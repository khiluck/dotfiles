# pauzer — таймер перерывов 40/5 для dwm

Рабочая программа-напоминалка: 40 минут работы → 5 минут перерыва с разминкой шеи.
Написана 2026-09-03. Этот файл — инструкция, как повторить всё вручную (в т.ч. после
переустановки системы) и где что лежит.

---

## 1. Что она делает

- Считает рабочий интервал (40 мин), потом объявляет перерыв (5 мин).
- За минуту до перерыва — уведомление через dunst (`notify-send`).
- В перерыв затемняет **все** мониторы (Xinerama), показывает крупный обратный отсчёт,
  прогресс-бар и **одно упражнение из комплекса** (по кругу, чтобы за день пройти весь
  комплекс). Клавиатуру забирает себе (как slock), чтобы набранное не улетело в окно
  под оверлеем. Звук на начало и конец перерыва.
- `Esc` / `q` — пропустить перерыв, `p` — отложить на 5 минут.
- Отсчёт **замирает**, если нет ввода дольше 2 минут (XScreenSaver): время вне стола не
  считается работой. Если тебя не было целый перерыв (5 мин) — это и был перерыв,
  интервал начинается заново и после совещания/обеда тебя не дёргают.
- Состояние пишет в `/tmp/pauzer`, откуда его берёт статус-бар dwm.

Индикаторы в баре:

| Текст | Значение |
|---|---|
| `🧘38m` | до перерыва 38 минут |
| `🧘38m⏸` | отсчёт заморожен, тебя нет за столом |
| `☕4:12` | идёт перерыв |
| `🧘off` | таймер выключен вручную |

## 3. Зависимости (Arch)

```sh
sudo pacman -S --needed base-devel libx11 libxft libxinerama libxss \
                        noto-fonts dunst libnotify libpulse xorg-xsetroot
```

- `libxss` — детект простоя (XScreenSaver), `libxinerama` — оверлей на каждом мониторе.
- `noto-fonts` — шрифт оверлея (в config.h прописан `Noto Sans`; кириллица есть).
- `dunst` + `libnotify` — предупреждение за минуту; `libpulse` — `paplay` для звуков.
- Полупрозрачность оверлея требует компоситора: в моём `~/.xinitrc` это `xcompmgr &`.
  Без него оверлей просто будет полностью непрозрачным.

## 4. Установка

### 4.1. Из архива (обычный путь при переустановке)

```sh
sudo mkdir -p /usr/src && sudo tar -xzf ~/claude/pauzer-src.tar.gz -C /usr/src
sudo chown -R aex:aex /usr/src/pauzer
cd /usr/src/pauzer
make
sudo make install
```

### 4.2. С нуля

Структура каталога (suckless-стиль, как у dwm):

```
/usr/src/pauzer/
├── Makefile        # цели all/clean/install/uninstall, config.h из config.def.h
├── config.mk       # пути, флаги; LIBS = -lX11 -lXss -lXinerama -lfontconfig -lXft
├── config.def.h    # ВСЕ настройки: тайминги, шрифты, цвета, тексты, упражнения, команды
├── config.h        # рабочая копия (создаётся из config.def.h при первой сборке)
├── pauzer.c        # ~600 строк: таймер, детект простоя, оверлей, сигналы, CLI
├── pauzer.1        # man
├── README
└── LICENSE         # MIT/X Consortium
```

Ключевое в `pauzer.c`, если восстанавливать руками:

- главный цикл — `select()` на fd X-соединения с таймаутом 1 с; шаг времени считается
  по `time(NULL)`, а не по числу итераций (устойчиво к suspend);
- простой — `XScreenSaverQueryInfo()`; `idle >= idlefreeze` → отсчёт замирает,
  `idle >= breaktime` → интервал начинается заново («перерыв уже был»);
- оверлей — по одному окну на каждый экран Xinerama, `override_redirect = True`,
  прозрачность через свойство `_NET_WM_WINDOW_OPACITY` (его понимает xcompmgr);
- рисование — в `Pixmap`, потом `XCopyArea` в окно (иначе мерцает раз в секунду);
- текст — `XftDrawStringUtf8` + свой перенос по словам (`drawwrapped`), чтобы длинные
  описания упражнений сами разбивались по ширине 3/4 экрана;
- клавиатура — `XGrabKeyboard` с повторами (как в slock), иначе набранное уходит в окно
  под оверлеем;
- сигналы: `SIGUSR1` = вкл/выкл, `SIGUSR2` = перерыв сейчас, `SIGHUP` = сброс интервала;
  CLI (`-p`, `-b`, `-r`) просто читает PID-файл и посылает сигнал.

## 5. Интеграция (три точки)

### 5.1. Автозапуск — `~/.xinitrc`

Перед `exec dwm`, рядом с запуском статус-бара:

```sh
~/scripts/dwm_status &

# break reminder: 40 min work / 5 min break
pauzer &
```

### 5.2. Статус-бар — `~/scripts/dwm_status`

Добавить функцию:

```sh
print_break(){
	[ -f /tmp/pauzer ] && printf "%s|" "$(cat /tmp/pauzer)"
}
```

и вставить `$(print_break)` в строку `xsetroot` перед датой:

```sh
xsetroot -name "...|$(whatismyip)|$(print_break)$(print_date)"
```

Бар обновляется раз в 60 с, но `pauzer` сам вызывает `refbar` при каждом изменении
текста, поэтому смена состояния видна сразу.

**Важно:** уже запущенный `dwm_status` держит функции в памяти — после правки его надо
перезапустить, иначе новый сегмент не появится:

```sh
pkill -f "dwm_stat[u]s"          # скобки, чтобы pkill не убил свою же оболочку
DISPLAY=:0 setsid nohup ~/scripts/dwm_status >/dev/null 2>&1 &
```

### 5.3. Хоткеи — `/usr/src/dwm/config.h`

Рядом с `cmdlock`:

```c
static const char *cmdbreaknow[]   = { "pauzer", "-b", NULL };
static const char *cmdbreaktoggle[]= { "pauzer", "-p", NULL };
static const char *cmdbreakreset[] = { "pauzer", "-r", NULL };
```

В массив `keys[]`:

```c
{ WINKEY,                       XK_n,      spawn,          {.v = cmdbreaknow } },
{ WINKEY|ShiftMask,             XK_n,      spawn,          {.v = cmdbreaktoggle } },
{ WINKEY|ControlMask,           XK_n,      spawn,          {.v = cmdbreakreset } },
```

Затем:

```sh
cd /usr/src/dwm && sudo make clean install
```

Хоткеи заработают только после перезапуска dwm (в моём config.h биндинг `quit`
закомментирован, значит нужен logout/login с tty1). Без перелогина то же самое доступно
командами `pauzer -b`, `pauzer -p`, `pauzer -r`.

### 5.4. Запустить, не дожидаясь перелогина

```sh
DISPLAY=:0 setsid nohup /usr/local/bin/pauzer >/tmp/pauzer.log 2>&1 &
```

## 6. Управление

| Команда | Хоткей | Действие |
|---|---|---|
| `pauzer -b` | `Win+n` | перерыв прямо сейчас |
| `pauzer -p` | `Win+Shift+n` | выключить / включить таймер |
| `pauzer -r` | `Win+Ctrl+n` | начать рабочий интервал заново |
| `pauzer -s` | — | показать текущий статус |
| `pauzer -v` | — | версия |

Во время перерыва: `Esc`/`q` — пропустить, `p` — отложить на 5 минут.
`pauzer -b` при выключенном таймере игнорируется — сначала `pauzer -p`.

## 7. Настройка — `/usr/src/pauzer/config.h`

После правки: `make && sudo make install`, затем перезапустить демон
(`pkill -x pauzer` и снова запустить, либо перелогиниться).

| Параметр | По умолчанию | Что это |
|---|---|---|
| `worktime` | `40 * 60` | длина рабочего интервала |
| `breaktime` | `5 * 60` | длина перерыва |
| `postponetime` | `5 * 60` | на сколько отодвигает клавиша `p` |
| `warntime` | `60` | за сколько до перерыва предупреждать |
| `idlefreeze` | `2 * 60` | после какого простоя замораживать отсчёт |
| `idlecredit` | `1` | считать длинное отсутствие уже состоявшимся перерывом |
| `fontbig/mid/small` | `Noto Sans …` | шрифты отсчёта, заголовков, описаний |
| `colbg/fg/accent/muted` | gruvbox | цвета (те же, что в баре dwm) |
| `opacity` | `0.96` | прозрачность оверлея (нужен компоситор) |
| `breaktitle`, `breakhint` | — | верхняя строка и подсказка по клавишам |
| `tips[]` | комплекс ниже | упражнения: `{ "название", "как делать" }` |
| `cmdwarn`, `cmdbreakstart`, `cmdbreakend` | notify-send / paplay | что запускать на событиях |
| `cmdbarrefresh` | `refbar` | чем толкать статус-бар |
| `statusfile`, `pidfile` | `/tmp/pauzer*` | пути состояния |

Тексты упражнений переносятся по строкам автоматически — писать их можно любой длины.

## 8. Комплекс упражнений (можно делать и без программы)

Короткий комплекс 2–4 раза в день, особенно после долгого сидения. Всё медленно, без
боли; через боль не тянуть.

1. **Подбородок назад (chin tuck).** Смотри прямо, голову не опускай. Медленно отведи
   подбородок назад, как будто делаешь «двойной подбородок». Задержись 3–5 секунд,
   расслабься. 8–10 повторений. Разгружает позу «голова вперёд» от компьютера.
2. **Повороты головы.** Медленно поверни голову вправо до комфортного предела →
   вернись → влево. По 5–8 раз в каждую сторону.
3. **Наклоны: ухо к плечу.** Плечи на месте. Наклоняешь голову вправо, затем влево.
   Лёгкое растяжение сбоку шеи, а не боль. По 5 раз.
4. **Растяжка верхней трапеции.** Наклони голову вправо, правой рукой совсем немного
   добавь веса; левое плечо тяни вниз. 20–30 секунд, затем другая сторона. По 2 раза.
5. **Растяжка мышцы, идущей к лопатке.** Поверни голову на ~45° вправо и посмотри вниз,
   будто смотришь в правый карман. Очень мягко потяни голову рукой вниз — растяжение
   сзади-сбоку шеи. 20–30 секунд, затем другая сторона.
6. **Лопатки назад.** Сидя или стоя расправь плечи и сведи лопатки немного назад и вниз,
   будто держишь между ними карандаш. 5 секунд × 10 раз. За ПК это иногда полезнее,
   чем разминать саму шею.
7. **Встань и пройдись.** Пройди по квартире, налей стакан воды: смена позы важнее
   любой растяжки.
8. **Отдых для глаз.** Смотри в окно на дальний объект 20 секунд, поморгай
   (правило 20-20-20). Потянись всем телом вверх, как после сна, три раза.

`pauzer` показывает по одному пункту на перерыв, по кругу: при 40-минутных интервалах
за рабочий день проходишь весь список примерно полтора раза.

## 9. Проверка и диагностика

```sh
pgrep -af "/usr/local/bin/pauze[r]"   # демон жив?
pauzer -s                             # текущий статус
cat /tmp/pauzer                        # то же, что читает бар
cat /tmp/pauzer.log                    # stderr демона
xprop -root WM_NAME                    # что реально в статус-баре dwm
xdotool search --class pauzer          # окна оверлея (в норме — только во время перерыва)
```

Если оверлей залип и забрал клавиатуру: с другого tty или из уже открытого терминала

```sh
pkill -x pauzer
```

Окна и захват клавиатуры снимаются при выходе, файлы `/tmp/pauzer*` удаляются.

Демон не запускается со словами `already running` — остался `/tmp/pauzer.pid` от живого
процесса; проверь `pgrep -x pauzer`, при необходимости удали файл.

## 10. Грабли, на которые я наступил (чтобы не повторять)

- **`sigpause` — занятое имя.** Переменная `sigpause` конфликтует с функцией из
  `<signal.h>` (glibc), сборка падает. Назвал `sigtoggle`.
- **Мерцание оверлея.** `XClearWindow` + перерисовка раз в секунду мигает и ломает
  скриншоты (строка подсказки попадала в кадр не нарисованной). Лечится рисованием в
  `Pixmap` и одним `XCopyArea`.
- **Шрифт `sans-serif`.** У меня fontconfig разрешает его в Linux Biolinum — на экране
  выглядит как засечки. Прописал конкретное `Noto Sans`.
- **`dwm_status` в памяти.** Правка скрипта не действует на уже запущенный процесс, надо
  перезапускать (см. 5.2).
- **`pkill -f <шаблон>`** убивает и собственную оболочку, если шаблон встречается в её
  командной строке. Пиши `pauze[r]` / `dwm_stat[u]s` или бей по PID.
- **Тестовый экземпляр.** При отладке я запускал сборку с 4-секундными интервалами —
  такой демон накрывает экран почти постоянно. Если тестируешь, обязательно проверяй
  `pgrep -a pauzer` и гаси лишнее.

## 11. Обновление и удаление

```sh
cd /usr/src/pauzer
# правки в config.h или pauzer.c
make && sudo make install
pkill -x pauzer && DISPLAY=:0 setsid nohup pauzer >/tmp/pauzer.log 2>&1 &

# удалить целиком
sudo make uninstall
# и убрать: строку pauzer & из ~/.xinitrc, print_break из ~/scripts/dwm_status,
# три биндинга из /usr/src/dwm/config.h (потом sudo make clean install в /usr/src/dwm)
```
